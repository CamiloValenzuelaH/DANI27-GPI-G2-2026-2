
  # Replica página con estilo

  ## Variables de entorno (Vite)

  - Crea un archivo `.env.local` en la **raíz** del proyecto (al lado de `package.json`).
  - Vite solo expone variables al cliente si empiezan con `VITE_`.

  Ejemplo:

  ```bash
  VITE_GEMINI_KEY=tu_api_key_de_gemini
  ```

  Luego reinicia el server (`npm run dev`).

  This is a code bundle for Replica página con estilo. The original project is available at https://www.figma.com/design/2Z8wFPlXuzhksHrMiJmHCD/Replica-p%C3%A1gina-con-estilo.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
