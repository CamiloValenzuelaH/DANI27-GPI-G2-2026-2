💡 EJEMPLO RÁPIDO
═══════════════════════════════════════════════════════════════════════════

❌ ANTES (No accesible):
┌─────────────────────────────────────────┐
│ <button onClick={handleClose}>           │
│   <XIcon size={24} />                    │
│ </button>                                 │
└─────────────────────────────────────────┘
Problema: Sin aria-label, sin focus ring

✅ DESPUÉS (Accesible):
┌──────────────────────────────────────────────────────┐
│ <button                                              │
│   onClick={handleClose}                             │
│   aria-label="Cerrar"                               │
│   className="focus:outline-none focus:ring-2"       │
│ >                                                    │
│   ✕                                                  │
│ </button>                                            │
└──────────────────────────────────────────────────────┘
Solución: aria-label + focus ring = ✓ Accesible
